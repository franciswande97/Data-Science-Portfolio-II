# Data Science Portfolio II

A collection of practical data science projects showcasing my development across data analysis, data preprocessing, machine learning, natural language processing, and neural networks.

## About This Portfolio

This repository brings together practical projects that demonstrate my ability to work with data, apply analytical techniques, explore patterns, and build data-driven solutions. Projects are organised by level to make the progression from foundational techniques to more advanced methods easy to follow.

### Level 2 — Intermediate Machine Learning

- [Task 1 — NLP Text Classification](Level-3-Advanced/Task-1/)
